# AWS End-to-End Data Engineering Pipeline

## 📌 Project Overview

This project demonstrates hands-on practice with AWS cloud services, Linux commands, MySQL, AWS IAM roles, AWS Lambda, Amazon CloudWatch, and Microsoft Azure storage services.

The objective is to understand cloud infrastructure, data storage, serverless computing, monitoring, database fundamentals, and access management.

## 🛠️ Technologies Used

- **AWS IAM** – Identity and Access Management
- **Amazon S3** – Cloud object storage
- **AWS Lambda** – Serverless computing
- **Amazon CloudWatch** – Monitoring and logging
- **MySQL** – Relational database management
- **Linux** – Command-line operations
- **Microsoft Azure** – Cloud platform
- **Azure Resource Groups** – Resource organization
- **Azure Storage Account** – Cloud storage management
- **Azure Blob Storage** – Object storage

## 📂 Project Modules

### 1. MySQL
- Database fundamentals and SQL practice.
- Understanding relational database concepts.

### 2. Linux Commands
- Practicing basic Linux terminal commands.
- Working with files, directories, and command-line operations.

### 3. AWS IAM and Amazon S3
- Understanding IAM roles and permissions.
- Configuring access between AWS services and S3 buckets.

### 4. AWS Lambda
- Exploring serverless computing.
- Understanding event-driven function execution.

### 5. Amazon CloudWatch
- Learning cloud resource monitoring.
- Exploring logs, metrics, and operational visibility.

### 6. Microsoft Azure
- Exploring Azure cloud resources.
- Understanding resource groups and cloud resource organization.

### 7. Azure Storage
- Learning about storage accounts.
- Exploring Azure Blob Storage for storing unstructured data.

## 🎯 Learning Objectives

- Understand fundamental cloud computing concepts.
- Practice Linux commands and database operations.
- Learn AWS IAM roles and access management.
- Explore serverless computing with AWS Lambda.
- Understand monitoring using Amazon CloudWatch.
- Gain exposure to Microsoft Azure storage services.
- Build practical experience with cloud platforms.

## 🚀 Key Takeaways

This project provides practical exposure to cloud computing, database management, serverless architecture, monitoring, access control, and cloud storage across AWS and Microsoft Azure.
